# 🌾 Деревенский Рай: Наследие

3D ферма-симулятор с сюжетом в стиле Stardew Valley / Harvest Moon на **Three.js** (HTML5, работает в браузере и внутри WebView-обёртки APK).

## 🚀 Запуск

Вариант 1 — просто открыть `index.html` (нужен любой статический сервер из-за ES-модулей):

```bash
npx serve .          # или: python3 -m http.server 8080
```

Затем открыть http://localhost:8080

Вариант 2 — собрать APK: см. `/apk` (WebView-обёртка, игра полностью офлайн внутри APK).

## 🎮 Управление

| Действие | ПК | Мобильное |
|---|---|---|
| Движение | WASD / стрелки | Виртуальный джойстик |
| Действие (вспахать/посадить/полить/собрать/говорить) | E | Кнопка E |
| Смена семян | Q | Кнопка 🌱 |
| Инвентарь | I / кнопка 🎒 | Кнопка 🎒 |
| Поворот камеры | мышь/свайп справа | свайп справа |

## 📖 Сюжет (4 главы = 4 сезона)

1. **🌸 Весна — «Возвращение»**: вспашка, первые семена, инспектор Громова портит грядки (день 6), оборона курятника.
2. **☀️ Лето — «Расцвет»**: корова, фестиваль (1500💰), пожар поля от Громова — потуши поливом.
3. **🍂 Осень — «Испытание»**: шахта деда в лесу (руда/самоцветы), убедить 3 жителей не продавать землю.
4. **❄️ Зима — «Финал»**: документы для суда (6000💰 заработка) и аукцион — заплатить Громову 8000💰.

**Концовка А**: заплатить на аукционе → ферма спасена.
**Концовка Б (секретная)**: найти сундук деда в лесу (появляется после квеста о шахте) → выкупить всю деревню.

## 🧩 Механики

- 8 культур с сезонностью, поливом и ростом по дням
- 4 вида животных (курица, корова, овца, пчёлы) с ежедневной продукцией
- Рыбалка (обычная и редкая рыба), добыча камня/руды/самоцветов
- 12 сюжетных квестов + 3 ежедневных задания
- 5 NPC с диалогами, событиями сюжета и подарками
- День/ночь цикл, смена сезонов с перекраской мира
- Сохранение в localStorage

## 💰 Монетизация (симуляция SDK)

В коде есть готовые точки интеграции (имитация с теми же хуками, что и у Yandex Mobile Ads / AdMob):

- **Rewarded video**: ×2 урожай при сборе, +50💰 после сна, второй шанс на редкую рыбу (лимит 5/день)
- **Interstitial**: между днями (не чаще 1 раза в 2 дня — «8 минут геймплея»)
- **Banner**: в главном меню

Для боевого SDK заменить `UI.showRewarded()` / `UI.showInterstitial()` на вызовы `RewardedAd.show()` / `InterstitialAd.show()`.

## 📁 Структура

```
index.html          — разметка и UI-оверлеи
css/style.css       — стили HUD, меню, диалогов
js/main.js          — игровой цикл, механики, квесты, события
js/world.js         — 3D-мир: ферма, деревня, река, лес, свет
js/player.js        — персонаж, управление, камера
js/npc.js           — NPC, животные, спрайт-имена
js/state.js         — состояние, сохранение
js/data.js          — культуры, животные, квесты, диалоги
vendor/three.module.js — Three.js r160
```
