# 🌾 Деревенский Рай: Экосистема

2D-стратегия-ферма (HTML5 Canvas, без движка и сборки), построенная **строго на ассетах из архива** репозитория.

## Запуск

Игра — статические файлы, нужен любой локальный сервер (ES-модули не работают с file://):

```bash
cd game
python3 -m http.server 8080
# открыть http://localhost:8080
```

Или просто открой deployed-версию: https://kiralitekova-code.github.io/-/eco/

## Управление

- **Мышь / тач** — все действия (клик по полю = посев/сбор, по загону = покупка скота, по зданию = постройка)
- **Пробел** — «Новый день»
- **Esc** — закрыть окно/подсказку

## Что в игре

- **Ферма**: 6 полей (4 культуры), лес (рубка), 4 загона (куры, овцы, коровы, лошади), 7 мини-цехов (пекарня, сыроварня, прядильня, кожевня, маслобойня, пивоварня, пасека)
- **Шахта**: руда, уголь, самоцветы, соль; глубина 1–5 (открывается отрядами), плавильня (2 руды + 1 уголь → железо)
- **Завод**: заказы с дедлайнами, караваны (до 50 ед., риск ограбления 15%, с охраной 5%)
- **Гильдия**: 3 вида отрядов (ополчение, лучники, рыцари), охрана караванов, углубление шахты
- **Рынок**: продажа/покупка, сезонные цены, ярмарка ×2
- **Склад**: лимиты еды/сырья, порча скоропортящегося (2%/день), автопродажа, журнал
- **Сезоны**: весна/лето/осень/зима — зимой поля не растут
- **События**: инспектор Громова, пожар, эпидемия, бродяги, ярмарка
- **Туториал**: 7 шагов
- **4 финала**: Симбиоз / Эксплуататор / Паразит / Возрождение
- Автосохранение (localStorage)

## Структура

```
game/
├── index.html
├── css/style.css
├── js/
│   ├── main.js       — игровой цикл, ввод, загрузка
│   ├── assetmap.js   — сгенерированный манифест: ключ → точный путь ассета
│   ├── assets.js     — загрузчик изображений
│   ├── data.js       — ресурсы, культуры, цеха, отряды, заказы, события, туториал
│   ├── state.js      — экономический движок
│   ├── ui.js         — панели, кнопки, текст
│   └── screens.js    — отрисовка экранов
└── assets/           — ТОЛЬКО файлы из архива пользователя (см. ../assets_raw)
```

## Чек-лист ассетов (Этап 4)

Все пути в `js/assetmap.js` (161 ассет) указывают на реальные файлы в `assets/` —
никаких внешних ссылок, CDN, сгенерированных картинок или placeholder'ов нет.
Проверка: `node check-assets.mjs`.
