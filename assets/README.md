# 📦 Ассеты игры «Деревенский Рай»

Сюда закидываются сгенерированные листы-сетки (PNG).

## Структура

| Папка | Что класть | Промпт |
|---|---|---|
| `icons/` | Лист иконок ресурсов (6×4) и продукции заводов (6×4) | Промпт 1, 2 |
| `buildings/` | Лист зданий фермы (4×3) | Промпт 3 |
| `characters/` | Лист персонажей (4×2) | Промпт 4 |
| `tiles/` | Лист тайлов мира (4×4) | Промпт 5 |
| `ui/` | Лист UI-элементов (3×3) | Промпт 6 |
| `split/` | Сюда я кладу нарезанные отдельные ассеты | (автоматически) |

## Правила
- Формат: PNG, чем больше разрешение — тем лучше (1536×1536+)
- Можно кидать ZIP — я распакую
- Игра будет использовать ТОЛЬКО эти файлы
